# Vinishaa K R Portfolio

A single-page React portfolio built with Vite, Framer Motion, and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

## Resume

Replace `public/resume.pdf` with the latest resume to update the Download Resume link.

## Contact email notifications

The contact form stores submissions in Firestore and sends notifications using the current `@emailjs/browser` SDK.

## Deploy on Netlify (Free plan)

For updates, push to the **main** branch; Netlify will build and publish the site automatically.

To preview a production build locally:

```bash
npm run build
npm run preview
```
